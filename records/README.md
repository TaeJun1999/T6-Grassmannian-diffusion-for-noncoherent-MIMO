## 운영 규칙 (드리프트 방지)
1. **세션 중 작업본 = Claude 프로젝트의 파일.** 세션이 끝나면 갱신본을 여기에 커밋한다(세션당 1커밋, 메시지에 날짜와 D/Q 번호).
2. 파일 이름은 항상 위 네 개 그대로. 프로젝트에 다시 올릴 때는 구판을 먼저 지워 `__1_` 접미사가 생기지 않게 한다.
3. 기록은 append-only. 과거 항목은 고치지 않고, 정정이 필요하면 새 날짜 항목에 "정정:"으로 적는다(이미 D-13, Q-12 (b)에서 그렇게 했다).
4. `SHA256SUMS.txt`는 커밋 시점의 해시. 프로젝트 사본과 저장소 사본이 같은지 한 줄로 확인할 수 있다: `sha256sum -c SHA256SUMS.txt`.

## 공개 저장소일 때
이 폴더는 문제 설정·베이스라인·상한·판정 기준을 전부 담고 있다. 저장소가 Public이면 논문 전에 아이디어 전체가 공개된다. Private 전환을 권하며, 공개 상태를 유지해야 한다면 이 폴더 대신 `PREREGISTRATION_HASH.txt`(내용을 드러내지 않고 시점만 증명)만 올린다.
